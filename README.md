<h1>CSS Best Practices</h1>
<p>
  Este README também está disponível em <a href="./README.pt-br.md">Português</a>.
</p>
<p>
  This repository contains practical examples and studies of CSS best practices, focusing on both SMACSS (Scalable and Modular Architecture for CSS) and BEM (Block Element Modifier) methodology. Each file includes comments explaining the concepts, with demonstrations of layout, modules, themes, forms, buttons, and interactive components.
</p>
<h2>Topics Covered</h2>
<ul>
  <li>SMACSS (Base, Layout, Modules, State, Theme)</li>
  <li>BEM Methodology (Block Element Modifier)</li>
  <li>CSS / SASS / SCSS</li>
  <li>HTML5</li>
  <li>JavaScript (Accordion Components)</li>
  <li>Forms and Buttons</li>
  <li>Theming (Tema A / Tema B)</li>
  <li>UI Components</li>
</ul>
<h2>Examples Included</h2>
<ul>
  <li><b>SMACSS Folder:</b> Layouts, modules, themes, accordions, and UI messages.</li>
  <li><b>BEM Folder:</b> Forms with BEM methodology applied using CSS and SASS.</li>
</ul>
<h2>How to Use</h2>
<p>
  Open the <code>index.html</code> file in the respective folder (SMACSS or BEM) in a browser to explore the examples. Examine the CSS/SASS files to understand how SMACSS and BEM are implemented. JavaScript is included for interactive elements like accordions.
</p>
