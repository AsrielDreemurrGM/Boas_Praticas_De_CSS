<h1>Boas Práticas de CSS</h1>
<p>
  This README is also available in <a href="./README.md">English</a>.
</p>
<p>
  Este repositório contém exemplos práticos e estudos sobre boas práticas de CSS, com foco nas metodologias SMACSS (Scalable and Modular Architecture for CSS) e BEM (Block Element Modifier). Cada arquivo possui comentários explicativos sobre os conceitos, com demonstrações de layouts, módulos, temas, formulários, botões e componentes interativos.
</p>
<h2>Tópicos Abordados</h2>
<ul>
  <li>SMACSS (Base, Layout, Módulos, Estado, Tema)</li>
  <li>Metodologia BEM (Block Element Modifier)</li>
  <li>CSS / SASS / SCSS</li>
  <li>HTML5</li>
  <li>JavaScript (Componentes Accordion)</li>
  <li>Formulários e Botões</li>
  <li>Theming (Tema A / Tema B)</li>
  <li>Componentes de Interface (UI)</li>
</ul>
<h2>Exemplos Incluídos</h2>
<ul>
  <li><b>Pasta SMACSS:</b> Layouts, módulos, temas, accordions e mensagens de UI.</li>
  <li><b>Pasta BEM:</b> Formulários aplicando a metodologia BEM com CSS e SASS.</li>
</ul>
<h2>Como Usar</h2>
<p>
  Abra o arquivo <code>index.html</code> na respectiva pasta (SMACSS ou BEM) em um navegador para explorar os exemplos. Analise os arquivos CSS/SASS para entender como SMACSS e BEM foram implementados. JavaScript está incluído para elementos interativos, como os accordions.
</p>
<h2>Tecnologias Utilizadas</h2>
<ul>
  <li>HTML5</li>
  <li>CSS / SASS / SCSS</li>
  <li>JavaScript</li>
  <li>Arquitetura SMACSS</li>
  <li>Metodologia BEM</li>
  <li>Formulários, Botões e Componentes Accordion</li>
  <li>Theming</li>
  <li>Componentes de Interface (UI)</li>
</ul>
